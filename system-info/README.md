# DevOps System Information Tool

A Bash-based system information tool built as part of my DevOps learning journey.

This project collects useful information about a computer's system, Git installation, and network configuration.

## Features

-Displays the currrent user
-Displays the home directory
-Displays the current directory
-Displays the current date and time
-Displays the operating system
-Displays the number of CPU cores
-Detects total RAM
-Checks whether Git is installed
-Displays the IPv4 address
-Displays the default network gateway
-Performs basic script error checking


## How to Run

1. Open Git Bash
2. Navigate to the project directory
3. Run the script using:

```bash
bash system-info.sh

The Script will display system, Git, and network information
